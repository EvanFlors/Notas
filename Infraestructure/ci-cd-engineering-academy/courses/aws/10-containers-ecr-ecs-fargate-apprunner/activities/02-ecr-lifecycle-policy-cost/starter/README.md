# Starter — ECR lifecycle policy

Copia estos archivos a tu directorio de trabajo:

```bash
mkdir -p /tmp/aws-10-ecr-lifecycle
cp -r ./* /tmp/aws-10-ecr-lifecycle/
cd /tmp/aws-10-ecr-lifecycle
```

- Rellena `lifecycle-policy.json` con al menos 3 reglas (ver instrucciones).
- Rellena `README-INTENT.md` con una seccion por regla, resumen y orden de
  evaluacion.
- Valida: `bash <ruta-actividad>/tests/validate.sh /tmp/aws-10-ecr-lifecycle`.
