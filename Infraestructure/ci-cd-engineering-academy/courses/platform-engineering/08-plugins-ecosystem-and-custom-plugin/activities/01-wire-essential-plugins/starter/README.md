# Starter — plat-08-01-wire-essential-plugins

Esta actividad es **independiente**: no hay código ni plantilla que ejecutar. Tu entregable es un documento Markdown escrito por ti.

## Pasos

1. Lee `../README.md` completo.
2. Prepara el directorio:
   ```bash
   mkdir -p /tmp/plat-08-wiring
   cd /tmp/plat-08-wiring
   ```
3. Crea `WIRING.md` con las cinco secciones (A: elección, B: `app-config.yaml`, C: anotaciones, D: `EntityPage.tsx`, E: tabla de auth).
4. Valida la estructura:
   ```bash
   bash <ruta-repo>/courses/platform-engineering/08-plugins-ecosystem-and-custom-plugin/activities/01-wire-essential-plugins/tests/validate.sh /tmp/plat-08-wiring
   ```
5. Compara tu documento con `../solution/REFERENCE.md` para autoevaluarte.

> **Importante:** el validador comprueba estructura, no semántica. La corrección conceptual la revisas tú contra la referencia.
