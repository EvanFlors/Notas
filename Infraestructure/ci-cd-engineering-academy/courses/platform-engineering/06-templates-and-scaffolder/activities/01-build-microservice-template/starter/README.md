# Starter — plat-06-01-build-microservice-template

Esta actividad es un **mini-project**: tienes un esqueleto con TODOs que debes completar.

## Pasos

1. Lee `../README.md` completo.
2. Prepara tu copia:
   ```bash
   mkdir -p /tmp/plat-06-build
   cp -r <ruta-repo>/courses/platform-engineering/06-templates-and-scaffolder/activities/01-build-microservice-template/starter/* /tmp/plat-06-build/
   cd /tmp/plat-06-build
   ```
3. Completa `template.yaml` según los TODOs comentados.
4. Completa cada archivo del `skeleton/` siguiendo los `# TODO:` presentes.
5. Valida:
   ```bash
   bash <ruta-repo>/courses/platform-engineering/06-templates-and-scaffolder/activities/01-build-microservice-template/tests/validate.sh /tmp/plat-06-build
   ```
6. Opcional: si tienes `cookiecutter` instalado, el validador intentará renderizar un dir `cookiecutter-skeleton/` análogo si lo creas. Si no existe, lo marca como SKIP.

> El validador comprueba **estructura**, no semántica. Compara con `../solution/TEMPLATE.md` para auto-evaluar.
