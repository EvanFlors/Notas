# Capstone Project

Proyecto integrador incremental: una aplicación backend en Python (FastAPI + PostgreSQL) que evoluciona hasta correr en Kubernetes bajo GitOps, con observabilidad, seguridad de supply chain y estrategias de despliegue.

El proyecto se desarrollará en **Fase 5** una vez disponibles los roadmaps especializados y los módulos relevantes de cada curso. Ver `ROADMAP.md` del repo raíz.

Etapas previstas (resumen; detalle en Fase 5):

1. App + tests
2. Git y versionamiento
3. CI (lint, test, build)
4. Containerización + registry
5. IaC con Terraform
6. Despliegue en cloud
7. Kubernetes
8. Helm + Argo CD (GitOps)
9. Observabilidad (Prometheus / Grafana / OTel)
10. DevSecOps (SBOM, firma, escaneos, policy)
11. Estrategias de release y rollback
12. Pruebas de carga y resiliencia
