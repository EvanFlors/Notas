# Starter — Chain de 3 roles

No hay código de arranque. Esta actividad es un diseño desde cero.

Recomendación: para cada role, empieza por `ansible-galaxy role init <nombre>` (si tienes ansible) o `mkdir -p roles/<nombre>/{defaults,tasks,meta,...}` a mano.

Lee `../README.md` para los requisitos exactos de cada role, y `../solution/REFERENCE.md` **sólo después** de intentarlo.
