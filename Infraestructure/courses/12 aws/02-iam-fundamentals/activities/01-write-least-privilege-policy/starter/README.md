# Starter — aws-02-01-write-least-privilege-policy

Esta actividad no tiene código. Tu entregable son dos ficheros escritos por ti.

## Pasos

1. Lee `../README.md` completo.
2. Prepara el directorio de trabajo:
   ```bash
   mkdir -p /tmp/aws-02-lpp
   cd /tmp/aws-02-lpp
   ```
3. Crea `POLICY.json` con la policy mínima (ver sección 5.2 del README).
4. Crea `JUSTIFICATION.md` con las 4 secciones (ver sección 5.3 del README).
5. Valida:
   ```bash
   bash <repo>/courses/aws/02-iam-fundamentals/activities/01-write-least-privilege-policy/tests/validate.sh /tmp/aws-02-lpp
   ```
6. Compara con `../solution/REFERENCE.md` para autoevaluarte.

> **Importante:** el validador comprueba estructura, no semántica fina. La justificación la revisas tú contra la referencia.
