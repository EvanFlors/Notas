# Recursos — sys-02

## Documentación oficial

- **Linux man-pages project** (manpages canónicas Linux, secciones 2/3/7) — <https://man7.org/linux/man-pages/>
- **GNU coreutils manual** (`ls`, `cp`, `rm`, `cat`, `sort`, `uniq`, `wc`, `head`, `tail`, `cut`, `tr`, `sha256sum`, `sudo`-no …) — <https://www.gnu.org/software/coreutils/manual/coreutils.html>
- **Bash reference manual**, "Shell Expansions" — <https://www.gnu.org/software/bash/manual/html_node/Shell-Expansions.html>
- **Bash reference manual**, "Shell Builtin Commands" — <https://www.gnu.org/software/bash/manual/html_node/Shell-Builtin-Commands.html>
- **POSIX Utilities Volume (The Open Group, SUSv4 / IEEE Std 1003.1-2017)** — <https://pubs.opengroup.org/onlinepubs/9699919799/utilities/contents.html>
- **GNU `grep` manual** — <https://www.gnu.org/software/grep/manual/grep.html>
- **GNU `sed` manual** — <https://www.gnu.org/software/sed/manual/sed.html>
- **GNU `awk` manual (gawk)** — <https://www.gnu.org/software/gawk/manual/gawk.html>
- **GNU `tar` manual** — <https://www.gnu.org/software/tar/manual/tar.html>

## Comunitario, muy útil

- **tldr-pages** (ejemplos cortos, mantenidos por comunidad) — <https://tldr.sh/>
- **cheat.sh** — <https://cheat.sh/> (`curl cheat.sh/tar`)
- **ExplainShell** (parsea una línea de comandos y la anota) — <https://explainshell.com/>

## Libros de referencia

- **The Linux Command Line**, William Shotts — <https://linuxcommand.org/tlcl.php> (CC BY-NC-ND, PDF libre).
- **UNIX and Linux System Administration Handbook (5.ª ed.)**, Nemeth et al. — bibliografía profesional estándar.
- **Advanced Programming in the UNIX Environment (3.ª ed.)**, W. Richard Stevens — para quien quiera entender syscalls (sección 2 de man).
