# Workspace de inicio — `sys-01-01-cli-tour`

`starter/` es solo un marcador; no necesitas copiarlo.

Cuando termines, ejecuta el validator:

```bash
bash ../tests/validate.sh
```

Variables opcionales:

- `WORKDIR` — ruta del workspace (default `/tmp/cli-tour`).
- `BASHRC` — ruta al bashrc a inspeccionar (default `~/.bashrc`).
