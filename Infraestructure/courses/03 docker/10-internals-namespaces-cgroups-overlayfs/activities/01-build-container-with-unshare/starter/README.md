# Starter — dkr-10-01-build-container-with-unshare

Esta actividad no necesita archivos de arranque: trabajas en `/tmp/mini-rootfs/`,
`/sys/fs/cgroup/mini/` y `/tmp/mini-notes/` siguiendo el README de la actividad.

**Plataforma:** Linux obligatorio. En macOS/Windows, arranca una VM Ubuntu con
`multipass launch` o `vagrant up` y ejecuta la actividad dentro.
