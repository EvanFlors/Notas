Esta actividad es **independiente**: no hay código ni plantilla que ejecutar. Tu entregable es un documento Markdown escrito por ti.

## Pasos

1. Lee `../README.md` completo.
2. Prepara el directorio:
   ```bash
   mkdir -p /tmp/plat-12-year-one
   cd /tmp/plat-12-year-one
   ```
3. Crea `YEAR-ONE-PLAN.md` con las secciones:
   - Resumen ejecutivo.
   - **Q1**, **Q2**, **Q3**, **Q4** (cada uno con objetivos, SLO targets, scope, riesgos, hiring/capacity).
   - **Escenarios** (crecimiento rápido, hiring freeze, consolidación post-merger).
   - **Métricas de éxito** (≥ 5 métricas con fuente y cadencia).
   - Roadmap resumen (tabla o ASCII).
4. Valida la estructura:
   ```bash
   bash <ruta-repo>/courses/platform-engineering/12-governance-at-scale-multi-tenant-deprecations-platform-slos/activities/02-year-one-plan/tests/validate.sh /tmp/plat-12-year-one
   ```
5. Compara tu documento con `../solution/REFERENCE.md` para autoevaluarte.

> **Importante:** el validador comprueba estructura, no semántica. La corrección conceptual la revisas tú contra la referencia.
