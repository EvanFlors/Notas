# Starter — plat-02-02-dx-interview-template

Esta actividad es **independiente**: no hay código. Tu entregable es un documento Markdown escrito por ti.

## Pasos

1. Lee `../README.md` completo.
2. Repasa `../../../theory/lesson.md` §9 (feedback loops explícitos).
3. Prepara el directorio:
   ```bash
   mkdir -p /tmp/plat-02-dx-interview
   cd /tmp/plat-02-dx-interview
   ```
4. Crea `TEMPLATE.md` con las **6 secciones** (5 bloques + Método) y al menos **6 preguntas abiertas**.
5. Valida la estructura:
   ```bash
   bash <ruta-repo>/courses/platform-engineering/02-golden-paths-paved-roads-and-developer-experience/activities/02-dx-interview-template/tests/validate.sh /tmp/plat-02-dx-interview
   ```
6. Compara tu plantilla con `../solution/TEMPLATE.md` para autoevaluarte.

> **Importante:** el validador comprueba estructura, no semántica. La calidad de las preguntas la revisas tú contra la referencia.
