# Starter — plat-01-01-map-your-org

Esta actividad es **independiente**: no hay código ni plantilla que ejecutar. Tu entregable es un documento Markdown escrito por ti.

## Pasos

1. Lee `../README.md` completo.
2. Prepara el directorio:
   ```bash
   mkdir -p /tmp/plat-01-map
   cd /tmp/plat-01-map
   ```
3. Elige la organización a mapear (real o ficticia; mínimo 5 equipos).
4. Crea `ORG_MAP.md` con las cuatro secciones (A: tabla de equipos, B: tabla de interacciones, C: diagrama ASCII, D: decisión sobre platform team).
5. Valida la estructura:
   ```bash
   bash <ruta-repo>/courses/platform-engineering/01-principles-team-topologies-and-cognitive-load/activities/01-map-your-org/tests/validate.sh /tmp/plat-01-map
   ```
6. Compara tu documento con `../solution/REFERENCE.md` para autoevaluarte.

> **Importante:** el validador comprueba estructura, no semántica. La corrección conceptual la revisas tú contra la referencia.
