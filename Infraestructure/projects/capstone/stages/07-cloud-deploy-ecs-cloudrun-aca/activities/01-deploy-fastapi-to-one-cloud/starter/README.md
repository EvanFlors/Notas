# Starter — capstone 07 activity 01

Pasos:

1. Escribe en `choice.txt` **una sola linea** con `aws`, `gcp` o `azure`.
2. Abre el directorio `terraform/<tu-cloud>/<servicio>/main.tf` y resuelve
   los `TODO 1..4`. Lee los comentarios junto a cada TODO para la pista.
3. Corre el validador. Debe terminar con `RESULT: 0 issue(s).`.

Las otras dos nubes puedes dejarlas como estan: el validador solo mirara la
que elegiste.
