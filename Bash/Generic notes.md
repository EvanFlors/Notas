# What is Linux?

Linux
- Is the kernel of a family of open-source Unix-like operating systems based on the Linux kernel.
- The Linux kernel is the core component of a Linux operating system. It manages hardware resources and allows software to communicate with the hardware.

Operating System (OS)
- An operating system is system software that manages computer hardware, software resources, and provides common services for computer programs.

Unix
- A powerful, multiuser (have different permissions levels active at the same time), multitasking (run multiple applications simultaneously) operating system that serves as the foundation for many modern operating systems.

Kernel
- The kernel is the central part of an operating system. It manages system resources and allows software to communicate with hardware.

GNU (GNU's Not Unix)
- A free software operating system that is Unix-like but does not contain any Unix code. It was developed by the Free Software Foundation (FSF) and is composed of various software components, including libraries, compilers, and utilities.
- GNU is often used in combination with the Linux kernel to create a complete operating system, commonly referred to as GNU/Linux.
- GNU General Public License (GPL) is a widely used free software license that guarantees end users the freedom to run, study, share, and modify the software. It is the license under which most GNU software is released.

# Linux Distributions

Distributions
- A Linux distribution (or distro) is a complete operating system built around the Linux kernel. It includes the kernel, system libraries, utilities, and applications.
- Different distributions may have different package management systems, default configurations, and software selections.
- Each distribution then adds additional software, configuration files, and package management systems to create a complete operating system. This allows to cater to different user needs and preferences, such as desktop environments, server setups, or specialized applications.

Ubuntu
- Ubuntu is a popular Linux distribution based on Debian. It is known for its user-friendly interface and ease of use, making it a good choice for beginners. It comes with a wide range of pre-installed software and has a large community for support.
- Personal use: Ubuntu is well-suited for personal use due to its user-friendly interface and extensive software availability.

CentOS
- CentOS (Community ENTerprise Operating System) is a Linux distribution that provides a free, enterprise-class, community-supported computing platform. It is based on the sources of Red Hat Enterprise Linux (RHEL) and aims to provide a stable and secure operating system for servers and workstations.
- Professional use: CentOS is often used in professional environments, particularly for servers and enterprise applications, due to its stability and long-term support.
